# Coding Resources

This file gives simple resources to help new students learn coding.  
These links and tools are easy to use and good for beginners.

## Websites for Learning

- W3Schools: good for HTML, CSS, JavaScript, and more  
- Codecademy: simple lessons for new coders  
- FreeCodeCamp: free practice and projects  
- Microsoft Learn: good for C# and .NET

## YouTube Channels

- Bro Code: easy videos for beginners
- Giraffe Academy: Nice guy and easy explanation on java 
- Programming with Mosh: clear lessons for C#  
- CS Dojo: simple coding explanations

## Tools for Coding

- Visual Studio Code: free and easy editor  
- GitHub: save your code online  
- .NET SDK: needed for C# projects

## Why These Resources Help

These resources are simple and good for practice.  
They help students learn step by step.  
They also give examples and exercises to understand coding better.
